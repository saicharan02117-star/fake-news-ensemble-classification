Classifiers

Three models, one explainable vote

Each model views the same TF-IDF feature matrix but reaches its prediction through a different decision method.

01
LR

Logistic Regression

Estimates a linear decision boundary between fake and real text using weighted terms and phrases.

  • Supervised classification
  • Strong text baseline
  • Efficient on sparse features
02
K

K-Nearest Neighbors

Compares the article vector with nearby labelled examples using cosine distance.

  • Similarity-based decision
  • No parametric boundary
  • Distance-weighted neighbors
03
DT

Decision Tree

Splits feature values through readable decision rules until it reaches a class prediction.

  • Rule-based partitions
  • Captures nonlinear patterns
  • Controlled tree depth
